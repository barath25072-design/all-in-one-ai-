ALL IN ONE AI – STARTER PROJECT
================================

இந்த ZIP-ல் உள்ளவை:
- index.html: App screen
- styles.css: Dark purple/blue design
- app.js: Language switch, demo chat, local UI interactions
- manifest.webmanifest + sw.js: PWA அடிப்படை

முக்கிய குறிப்பு:
இது FRONTEND STARTER / UI DEMO மட்டுமே.
இன்னும் OpenAI API அல்லது வேறு AI backend இணைக்கப்படவில்லை.
Login, cloud chat history, உண்மையான PDF/image analysis, voice response ஆகியவை முழுமையாக செயல்படுத்தப்படவில்லை.

மொபைலில் பயன்படுத்த:
1. ZIP-ஐ extract செய்யவும்.
2. கோப்புகளை GitHub repository அல்லது Replit project-ல் upload செய்யவும்.
3. index.html-ஐ HTTPS hosting மூலம் வெளியிடவும்.
4. Chrome-ல் வெளியிடப்பட்ட HTTPS link திறக்கவும்.
5. Browser menu > Add to Home screen / Install app பயன்படுத்தவும் (விருப்பம் browser-ஐப் பொறுத்தது).

அடுத்த கட்டம்:
- Secure backend (API key server-side மட்டும்)
- AI model integration
- Authentication + database
- Image/PDF upload processing
- Voice responses
- Testing and Android packaging

பாதுகாப்பு:
OpenAI API key-ஐ index.html, app.js அல்லது Android app-ல் நேரடியாக எழுத வேண்டாம்.
API key server-side secret ஆக மட்டும் வைத்திருக்க வேண்டும்.

Play Store:
Play Store-ல் வெளியிட Google Play developer account மற்றும் அதன் தற்போதைய கட்டண/சோதனை/verification தேவைகள் பொருந்தும். ₹0 budget-ல் Play Store publishing-ஐ உறுதி செய்ய முடியாது.
